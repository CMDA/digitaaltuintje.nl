# Ring

Het is een webring voor met de hand gemaakte websites van studenten van de Bachelor Communication & Multimedia Design (CMD) aan de Hogeschool van Amsterdam (HvA). CMD student? Voeg jouw site toe met een pull-request.

## Site toevoegen

Als CMD student kan je zelf jouw site toevoegen aan het overzicht. Om dat te doen volg je het volgende stappenplan:

- _Fork_ deze repository
- Clone de _forked_ repository naar jouw lokale werkomgeving
- Open het bestand `webring.json` in jouw favoriete editor
- Voeg jouw gegevens onderaan het bestand toe, gebruik bij `cohort` het huidige jaartal
- _Push_ jouw aanpassing naar de _forked_ repository
- Doe een _pull-request_ terug naar deze repository

NB: Kom je er niet uit, vraag dan een van jouw tech-docenten om hulp.
